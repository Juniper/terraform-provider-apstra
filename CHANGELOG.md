# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## v0.108.0 - 2026-09-19
### FEATURES
* Added input validation to ensure that `vn_singles` map entries of `apstra_datacenter_connectivity_template_interface` resources do not use Apsra 6.2.0's `override_vlan` feature without `tagged = true`.
### BUG FIXES
* #1335 Value Conversion Error when design API objects use tags.

## v0.107.0 - 2026-09-17
### FEATURES
* Added support for DCI L3 Policy via the `apstra_datacenter_interconnect_domain_layer_3_policy` resource and data source.
* Add `apstra_datacenter_interconnect_domain_connection_type` resouce and data source.
* Introduced support for new roles in the `apstra_datacenter_resource_pool_allocation` resource: `access_l3_peer_links_ipv6`, `access_loopback_ips_ipv6`, `external_vn_local_vnis` and `vtep_ips_ipv6`
### BUG FIXES
* #1330 - Don't send `0` for VN Single `override_vlan` attribute when value is `null`






## v0.106.0 - 2026-09-08
### FEATURES
* Introduce support for `apstra_datacenter_virtual_network.encapsulate_inner_vlan`







## v0.105.0 - 2026-08-26
### FEATURES
* Introduce `apstra_design_tag` resource and data sources.
* Introduced `apstra_design_logical_device` resource and data source to replace `apstra_logical_device`.
* Introduce `apstra_device_profile` data source for discovering Device Profile IDs.
* Addded Apstra 6.2.0 to supported releases list.
### BUG FIXES
* Fix issue #1230 in `apstra_freeform_aggregate_link` resource
* `apstra_datacenter_device_allocation` will remove existing tags if `system_attributes.tags == null` during create phase.
### DEPRECATIONS
* The `apstra_tag` resource and data source will be removed no earlier than v2.0.0. Users should migrate their configurations to use the `apstra_design_tag` drop-in replacements.
* The `apstra_logical_device` resource and data source will be removed no earlier than v2.0.0. Users should migrate their configurations to use the `apstra_design_logical_device` drop-in replacements.
