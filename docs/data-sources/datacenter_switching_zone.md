# apstra_datacenter_switching_zone (Data Source)

This resource returns details of a Switching Zone within a Datacenter Blueprint.

At least one optional attribute is required. Requires Apstra >=6.2.0.


## Example Usage

```terraform
# This example pulls the details of a switching zone using
# manually-entered blueprint and switching zone IDs.
#
# In a production scenario it's more likely that these
# values would come from a lookup by name or from the
# read-only attributes of the resources which created
# them.

data "apstra_datacenter_switching_zone" "by_id" {
  blueprint_id = "f526f3dd-d814-4a1c-bd4b-950eabf82d13"
  id           = "OHOsoQ4zk-oKrAYaPA"
}

output "apstra_datacenter_switching_zone_by_id" {
  value = data.apstra_datacenter_switching_zone.by_id
}

# The output looks like this:

# apstra_datacenter_switching_zone_by_id = {
#   "blueprint_id" = "f526f3dd-d814-4a1c-bd4b-950eabf82d13"
#   "description" = "description"
#   "id" = "OHOsoQ4zk-oKrAYaPA"
#   "mac_vrf_name" = "mac_vrf_name"
#   "name" = "name"
#   "route_target" = "100:10001"
#   "service_type" = "vlan_bundle"
#   "tags" = toset([
#     "bar",
#     "baz",
#     "foo",
#   ])
# }
```

## Schema

### Required

- `blueprint_id` (String) Apstra Blueprint ID.

### Optional

- `id` (String) Apstra graph node ID. Required when `name` and `mac_vrf_name` are omitted.
- `mac_vrf_name` (String) MAC VRF name used on network devices and visible in the web UI. Required when `id` and `name` are omitted.
- `name` (String) Switching Zone Name. Required when `id` and `mac_vrf_name` are omitted.

### Read-Only

- `description` (String) Description displayed in the web UI.
- `route_target` (String) Route Target unique to the MAC-VRF Switching Zone.
- `service_type` (String) MAC VRF Service Type
- `tags` (Set of String) Set of Tags associated with the Switching Zone.
