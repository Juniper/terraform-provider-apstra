# apstra_datacenter_virtual_network_assignment (Data Source)

This data source retrieves Virtual Network to Leaf Switch and Access Switches assignment detail within a *Datacenter* Blueprint.


## Example Usage

```terraform
# This example looks up the details of a virtual netwwork assignment to a
# leaf switch in a datacenter blueprint.

data "apstra_datacenter_virtual_network_assignment" "example" {
  blueprint_id       = "9d129116-64f1-47a7-8aec-9b85a738e0d8"
  virtual_network_id = "ZQj_44XIXhUpliToIw"
  leaf_switch_id     = "eOZMiuxJyLCdpDStRA"
}
```

## Schema

### Required

- `blueprint_id` (String) ID of the Blueprint in which this Virtual Network Assignment is being retrieved.
- `leaf_switch_id` (String) ID of the Leaf Switch assignment to retrieve.
- `virtual_network_id` (String) ID of the Virtual Network assignment to retrieve.

### Read-Only

- `access_switch_ids` (Set of String) IDs of any access switch children of the Leaf Switch (or the peer Leaf Switch in a redundancy group) where this Virtual Network is available.
- `ipv4_address` (String) The IPv4 address to assign to the Leaf Switch on this Virtual Network, if any.
- `ipv4_mode` (String) Mode for assigning an IPv4 address to the Leaf Switch on this Virtual Network.
- `ipv6_address` (String) The IPv6 address to assign to the Leaf Switch on this Virtual Network, if any.
- `ipv6_mode` (String) Mode for assigning an IPv6 address to the Leaf Switch on this Virtual Network.
- `vlan` (Number) VLAN on the Leaf Switch for this Virtual Network.
